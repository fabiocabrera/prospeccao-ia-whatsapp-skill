# Prospecção WhatsApp com IA / AI WhatsApp Prospecting

## Português

Uma skill pública para Claude Code que orienta a construção de um sistema multiempresa de prospecção ativa: busca de empresas no Google Places, enriquecimento por CNPJ, campanhas com templates oficiais do WhatsApp, agente de IA e CRM leve.

Ela descreve arquitetura, integrações, comportamento do agente, segurança, conformidade e uma sequência de prompts de construção. Não contém credenciais nem dados de uma operação real.

### Instalação em 3 passos

1. Baixe o repositório (`git clone`) e copie a pasta `skills/prospeccao-whatsapp-ia` para `~/.claude/skills/` (Windows: `C:\Users\SEU_USUARIO\.claude\skills\`). Para usar só em um projeto, copie para `.claude/skills/` dentro dele.
2. Reinicie a sessão ou recarregue as skills do ambiente.
3. Peça ao Claude para usar `prospeccao-whatsapp-ia` ao planejar ou construir o sistema.

## English

A public Claude Code skill for building a multi-tenant outbound prospecting system: company discovery with Google Places, company-registry enrichment, campaigns using official WhatsApp templates, an AI agent, and a lightweight CRM.

It covers architecture, integrations, agent behavior, security, compliance, and a sequence of build prompts. It contains no credentials or real operational data.

### Installation in 3 steps

1. Download the repository (`git clone`) and copy the `skills/prospeccao-whatsapp-ia` folder into `~/.claude/skills/` (Windows: `C:\Users\YOUR_USER\.claude\skills\`). To use it in a single project, copy it to `.claude/skills/` inside that project.
